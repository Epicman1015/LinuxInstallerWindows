# LinuxInstallerWindows
A application that lets you install Linux from Windows


**WARNING:** EXTREMELY EXPERIMENTAL!!! DO NOT USE ON A MACHINE WITH IMPORTANT STUFF ON IT!!!

Linux Installer Windows **will be** an app that lets you easily install Linux from your Windows desktop
to either dual boot or replace your Windows partition.

It will support either UEFI or Legacy BIOS

Before using ensure:
- Secure Boot is turned off (probably will be temporary)
